# Resources

This folder contains resources for building the Electron application:

- `icon.ico` - Windows application icon (256x256)
- `icon.icns` - macOS application icon
- `icons/` - Linux icons folder (various sizes: 16x16, 32x32, 48x48, 128x128, 256x256, 512x512)

## Creating Icons

You can use tools like:

- [electron-icon-builder](https://github.com/nicholaswmin/electron-icon-builder)
- [iconutil](https://developer.apple.com/library/archive/documentation/GraphicsAnimation/Conceptual/HighResolutionOSX/Optimizing/Optimizing.html) (macOS)
- Online converters like [icoconvert.com](https://icoconvert.com/)

Place your icons here before building the application.
